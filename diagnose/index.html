症状逆引き診断

モンステラの異変から、考えられる原因と対処を絞り込みます。質問は 2 ステップで完了します。

これは確定診断ではなく、症状から推定される可能性の高い原因です。複数の症状が当てはまる場合は、複数の原因が重なっていることもあります。

下記は全症状と考えられる原因・対処の一覧です。JavaScript が有効な環境では、ステップ式の診断ツールで絞り込めます。

🌿 葉：葉の色・形・ハリの異常

葉が全体的に黄色くなる

緊急度：高

水のやりすぎ・根腐れの初期

鉢内が常に湿った状態で、根が酸素不足を起こしている可能性。最も多い原因。

すぐできる対処

水やりを完全停止し、土を完全に乾燥させる。サーキュレーターで通気を確保。

詳しく：病害虫・トラブル →
緊急度：低

自然な下葉の老化

株の最も下の葉が時間経過で黄変するのは生理的に正常な範囲のことも。

すぐできる対処

他の葉が健康なら経過観察で問題なし。気になる古い葉は剪定可能。

詳しく：季節管理・剪定・増やし方 →
緊急度：中

肥料過多・塩類集積

与えすぎた肥料が土壌に蓄積し、根が水分を吸えなくなっている可能性。

すぐできる対処

施肥を中止し、たっぷりの水で鉢底から流して塩類を流す。

詳しく：育て方の基本 →

葉先や周縁が茶色く枯れ込む

緊急度：中

空気の乾燥

特に冬の暖房期、湿度が極端に下がると葉先から枯れ込む典型的なサイン。

すぐできる対処

加湿器や葉水で湿度 50〜70% を維持する。

詳しく：育て方の基本 →
緊急度：中

肥料過多による塩類過剰

土壌の塩類濃度が高くなり、根の水分吸収が阻害されている。

すぐできる対処

施肥を停止し、用土の更新も検討する。

詳しく：育て方の基本 →
緊急度：中

水切れ

長期間の水不足で葉先から乾燥が進んでいる。

すぐできる対処

土の乾き具合を確認し、必要なら鉢底から流れるまでたっぷり給水。

詳しく：育て方の基本 →

葉の表面に褐色〜黒の斑点・薄い茶色

緊急度：中

葉焼け（強い直射日光）

直射日光や急激な光量変化で組織が損傷した状態。一度焼けた部分は回復しない。

すぐできる対処

レースカーテン越しの明るい日陰へ移動。焼けた葉は気になるなら剪定。

詳しく：病害虫・トラブル →

新葉だけが小さく弱々しい

緊急度：中

日照不足

光が不足していて、株が十分なエネルギーを得られていない。

すぐできる対処

より明るい窓際へ移動するか、植物育成 LED を併用する。

詳しく：育て方の基本 →
緊急度：中

根詰まり

2 年以上植え替えていない場合、鉢内で根が回りきって新しい成長を支えられない。

すぐできる対処

鉢から抜いて根を確認し、必要なら 1 サイズ大きい鉢へ植え替え。

詳しく：季節管理・剪定・増やし方 →

成熟株なのに新葉に切れ込みが入らない

緊急度：中

省エネモード（環境ストレスのサイン）

株がエネルギーを節約する状態に入っており、切れ込みを作る余裕がない。複数の原因が重なっていることが多い。

すぐできる対処

日照・根詰まり・温度ストレス・水分ストレスを総合的に見直す。

詳しく：病害虫・トラブル →
緊急度：低

株がまだ成熟していない

幼い株では生理的に切れ込みのない丸い葉のみが出る。

すぐできる対処

適切な管理を続けて、十分に成長するのを待つ。

詳しく：基礎知識 →

葉裏に微小な赤茶〜白の点・葉全体がカスリ状

緊急度：中

ハダニ

乾燥した環境を好む害虫。冬の暖房期に発生しやすく、放置すると葉全体が色抜けする。

すぐできる対処

葉水で湿度を上げる予防と、発生時は葉裏を水で洗い流す。広範囲なら殺虫剤。

詳しく：病害虫・トラブル →

葉脈に沿うかすり状の銀白色斑

緊急度：中

アザミウマ（スリップス）

体長 1〜2mm の細長い微小昆虫。新芽や葉裏に寄生し、表皮を破壊して吸汁。被害組織が銀白色に反射する。ウイルス病の媒介者でもある。

すぐできる対処

黄色〜青色の粘着トラップで初期捕獲。広範囲なら浸透移行性殺虫剤（オルトラン粒剤等の観葉植物適用品）を株元へ。

詳しく：病害虫・トラブル →

葉や茎に白い綿状のかたまり・茶色いカサブタ状

緊急度：中

カイガラムシ

茎や葉に固着する害虫。ベタつく排泄物がすす状の汚れの原因にもなる。

すぐできる対処

歯ブラシや綿棒で物理的にこすり落とす。広範囲なら市販の殺虫剤を使用。

詳しく：病害虫・トラブル →

葉裏に白い粉状の小虫が密集・葉を揺らすと一斉に舞う

緊急度：中

コナジラミ

全長 3mm 以下の白い羽虫。葉裏に密集して吸汁し、加害部位が白っぽく退色。甘い排泄物ですす病を誘発、ウイルス病も媒介する。

すぐできる対処

黄色粘着トラップで誘引。葉裏へ薬剤を散布。サーキュレーターで風を当て発生を抑える。

詳しく：病害虫・トラブル →

新芽や柔組織に黄〜緑〜黒の小虫が群がる

緊急度：中

アブラムシ

極めて高い繁殖力で集団寄生。葉の巻き込み・縮れを引き起こし、甘い排泄物（甘露）ですす病を誘発。モザイクウイルス等の媒介者でもある。

すぐできる対処

強めのシャワーで物理的に洗い流す。広範囲なら浸透移行性殺虫剤を株元に。

詳しく：病害虫・トラブル →

葉面に不整形の黒褐色斑点が広がる（屋外管理時）

緊急度：高

カビ・細菌性の葉斑病害

炭疽病・斑点細菌病・葉枯病など。室内では稀ですが、屋外管理や過湿環境では発生することがあります。同心円状に広がるのはカビ性、葉脈に沿う水浸状なら細菌性の可能性。

すぐできる対処

発病葉を即時切除してビニール袋に密閉廃棄。風通しを確保し、器具を消毒。広範囲なら観葉植物適用の殺菌剤（カビ性ならベンレート系、細菌性なら銅殺菌剤）を規定濃度で使用。

詳しく：病害虫・トラブル →

葉のハリ・光沢が落ちて頼りない柔らかさ

緊急度：高

根腐れの初期サイン

根が酸素不足で機能低下を起こしている可能性。3〜5日で乾く土が 1 週間以上湿っていれば要警戒。

すぐできる対処

水やりを停止して土を完全に乾かす。サーキュレーターで通気。

詳しく：病害虫・トラブル →
緊急度：低

水切れ

反対に水が不足してハリを失っている可能性も。土が完全に乾ききっていれば。

すぐできる対処

土の状態を確認し、乾いていれば鉢底から流れるまでたっぷり給水。

詳しく：育て方の基本 →

🪵 茎・幹：主茎の変色・軟化・倒伏

地際の主茎が黒〜黒褐色でブヨブヨ

緊急度：高

根腐れの末期（軟腐病）

腐敗が地際まで及んでいる深刻な状態。通常の植え替えでは救えない段階。

すぐできる対処

上部の健全な緑色部位（節と気根含む 10〜15cm）を切り出し、水挿しでクローン救出を試みる。

詳しく：病害虫・トラブル →

茎にしわが寄っている

緊急度：高

根の機能不全（根腐れ進行）

根が水を吸えず、茎が水分を失ってしわが寄っている。

すぐできる対処

株を抜いて根の状態を確認。腐敗根は除去し、無菌用土で植え替え。

詳しく：病害虫・トラブル →
緊急度：中

長期の水切れ

土が完全に乾ききった状態が長く続いた可能性。

すぐできる対処

土を確認し、完全に乾いていればたっぷり給水して様子見。

詳しく：育て方の基本 →

自重を支えられず倒れる

緊急度：高

根腐れによる固定力低下

根が機能していないため、株が土に固定されていない。

すぐできる対処

根の状態を確認し、必要なら緊急切除＋植え替え、または上部のクローン救出。

詳しく：病害虫・トラブル →
緊急度：低

支柱の不足

健康な株でも葉が大きく重くなると自立しにくい。

すぐできる対処

ヘゴ棒・水苔ポール等の支柱を設置して誘引する。

詳しく：季節管理・剪定・増やし方 →

🪴 根・鉢の中：根の異変・鉢内の状態

鉢底や土からドブ臭・腐敗臭

緊急度：高

根腐れの進行

嫌気性菌が増殖して根を分解している深刻なサイン。

すぐできる対処

株を抜いて根を確認。腐敗根を除去し、清潔な無菌用土に植え替え。

詳しく：病害虫・トラブル →

根が黒くブヨブヨ・引っ張ると抜ける

緊急度：高

根腐れの中度〜重度

腐敗が広範囲に及んでいる状態。早急な対処が必要。

すぐできる対処

腐敗根をすべて除去し、白く硬い健康な根だけを残して植え替え。

詳しく：病害虫・トラブル →

鉢底から大量に根が飛び出している

緊急度：中

根詰まり

鉢が小さくなりすぎている状態。生育が鈍り、新葉も小型化する。

すぐできる対処

成長期（春〜初夏）に 1 サイズ大きい鉢へ植え替え。

詳しく：季節管理・剪定・増やし方 →

土の表面に小さな黒い虫（コバエ）が飛んでいる

緊急度：中

キノコバエ（コバエ）

用土が常に湿っているのが主因。幼虫は根を食害することも。

すぐできる対処

水やり間隔を空けて土を乾燥気味に、表土を赤玉土や軽石で覆って卵が産み付けられない環境に。

詳しく：病害虫・トラブル →

🌱 全体：株全体に関する症状

成長期なのに新芽が出ない・止まる

緊急度：高

根腐れの初期サイン

根が機能低下し、新しい成長を支えられない状態の可能性。

すぐできる対処

水やり頻度と土の乾き具合を確認し、過湿なら停止して乾燥療法。

詳しく：病害虫・トラブル →
緊急度：中

日照不足

光合成エネルギーが足りず、新葉を展開する余力がない。

すぐできる対処

より明るい場所へ移動するか、植物育成 LED を併用。

詳しく：育て方の基本 →
緊急度：低

冬の休眠

冬は生育が緩慢になるのが正常。

すぐできる対処

水やりを控えめにして、施肥は完全停止。春を待つ。

詳しく：季節管理・剪定・増やし方 →

土が長期間（1週間以上）湿ったまま

緊急度：高

排水不良・根の吸水機能低下

用土の劣化、または根腐れで根が水を吸えなくなっている。

すぐできる対処

水やりを停止して通気を確保。改善しなければ用土・根の状態を確認。

詳しく：病害虫・トラブル →
緊急度：中

鉢が大きすぎる

株のサイズに対して鉢と土の量が多すぎると、土が乾きにくくなる。

すぐできる対処

次回植え替え時に株のサイズに合った鉢へ。鉢サイズアップは 1 段階まで。

詳しく：季節管理・剪定・増やし方 →
